# LinguaHub
Учебный сайт для английского и немецкого.

## Запуск
npm install
npm start
Открыть http://localhost:3000

## Render
Build Command: npm install
Start Command: npm start
Root Directory: пусто

В проекте есть курс A1–C2, задания, теория-конспект, оригинальные адаптированные истории,
словарь с переводом и озвучкой, практика и серверная точка /api/ai.
Настоящий AI можно подключить позже через сервер и переменную окружения; ключ нельзя помещать в public.
